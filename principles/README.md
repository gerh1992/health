# Principles

Capa de **por qué** del sistema. Aquí viven las reglas estables: qué se optimiza, qué no, y los criterios mecanísticos que gobiernan cómo se entrena, se mide y se decide.

Relación entre capas (cascada):

1. `principles/` → **por qué** (esto; estable, cambia poco)
2. `systems/` → **cómo** (modelos y protocolos por dominio) — *pendiente*
3. `performance/` → **qué pasó** (datos operativos, CSV)

Regla de oro: **los principios mandan, los datos los confirman o los falsifican.** Un dato que contradice un principio no rompe el principio: exige revisión.
